# Lavanya Peddada | Personal Portfolio

A modern, responsive personal portfolio website for Lavanya Peddada, a Data Science Engineering student at Aditya University.

## About the project

This internship Task 1 project presents Lavanya's education, technical skills, practical data projects and contact information in a clean portfolio experience designed for internship applications.

## Features

- Responsive layout for desktop, tablet and mobile
- Sticky navigation with a JavaScript mobile menu
- Smooth scrolling and active section navigation
- Accessible semantic HTML5 structure and form labels
- Client-side contact form validation with friendly feedback
- Scroll reveal animations using the Intersection Observer API
- Project, education, skills and strengths sections
- CSS-only data science dashboard hero visual with floating skill cards

## Technologies used

- HTML5
- CSS3 (Grid, Flexbox, custom properties and media queries)
- Vanilla JavaScript

## How to run locally

1. Open the `Lavanya-Portfolio` folder in VS Code.
2. Install the **Live Server** extension if it is not already installed.
3. Right-click `index.html` and choose **Open with Live Server**.
4. The website will open in your browser.

The site also works by opening `index.html` directly, although Live Server is recommended for development.

## Deploy using GitHub Pages

1. Create a GitHub repository and upload the contents of this folder.
2. Open the repository's **Settings** and select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.
5. GitHub will provide a public Pages URL after deployment finishes.

## Customization

You can update the contact email, LinkedIn and GitHub URLs in `index.html`, and edit text, project details and colors in the corresponding files.
